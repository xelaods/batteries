# バッテリー（batteries）

iPhone・PC・AirPods・マウスの電池残量を iPhone のウィジェットに表示します。
標準のバッテリーウィジェットと違い、**接続が切れても最後に受け取った値と時刻を表示し続けます**。

```
Windows PC（何台でも）                         iPhone
┌──────────────────────┐   ntfy.sh（中継）  ┌──────────────────────┐
│ バッテリー送信（常駐）│ ───────────────▶ │ バッテリーアプリ      │
│ ・PC 本体の電池       │    合言葉で共有    │ ・ウィジェット        │
│ ・近くの AirPods      │                    │ ・最後の値をずっと保持│
│ ・マウス（予定）      │                    │ ・iPhone 本体の電池   │
└──────────────────────┘                    └──────────────────────┘
```

## なぜ PC 経由なのか

iOS は AirPods の電池情報をほかのアプリに渡しません（AirPods の電波も、標準ウィジェットの情報源も、アプリからは読めないことを実機で確認済み）。
Windows は AirPods の電波を受け取れるので、PC の常駐アプリが読み取って iPhone に送ります。

- AirPods の値が更新されるのは、**どれかの PC が起動していて、AirPods がその近くにあるとき**（ケースを開けたとき・使っているとき）
- 外出中は、最後に PC が読んだ値と「◯時間前」が表示され続けます

## 使い方

### 1. PC（Windows 10 / 11）

1. **Releases** の `pc-build-番号` から `BatteriesPC-番号.exe` をダウンロードして起動（インストール不要）
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
2. 画面に QR コードと合言葉が出ます。初回は Windows の起動時に自動で起動するよう設定されます
3. 画面を閉じてもタスクトレイで動き続けます（終了はトレイのアイコンを右クリック）

**2台目以降の PC**：同じように起動し、「ほかの PC の合言葉を使う」に1台目の合言葉を入れます。

### 2. iPhone

1. **Releases** の最新（`build-番号`）から `Batteries-unsigned-番号.ipa` をダウンロードし、普段の署名ツールで署名してインストール
2. PC に出ている QR コードを **iPhone のカメラ** で読み取る → バッテリーアプリが開いて登録されます
   （読み取れないときは、アプリの「PC 連携」に合言葉を入力）
3. ウィジェットを使うには「設定 › ウィジェット › カレンダーへのアクセスを許可」（署名に App Group が入らない場合）

## 複数の PC

- PC ごとに別の機器として並びます（電源が切れている PC は最後の値のまま）
- AirPods は、どの PC が読んでも1台にまとめます。電池ごとに「実際に読み取った時刻」を持たせているので、新しい値だけが残ります

## 送る頻度と中継について

- 値が変わったときは10分ごと、変わらなくても1時間ごとに送ります（1台あたり1日最大144件で、ntfy.sh の無料枠の範囲）
- 中継には登録不要の [ntfy.sh](https://ntfy.sh) を使います。合言葉（推測できないランダムな文字列）を知っている人だけが読めます。中身は機器の名前と電池残量だけです
- ntfy.sh には12時間ほど残ります。iPhone 側はずっと最後の値を保存します
- ウィジェットも自分で受け取りに行きます（間隔は iOS が決めるので15分〜1時間程度）

## マウス（VXE）

2.4GHz レシーバーの電池の読み方を調べている段階です。PC のトレイメニュー「マウスの情報を書き出す」で、デスクトップに `batteries-hid.txt` ができます。

## ビルド（Mac 不要）

`main` に push すると GitHub Actions が自動でビルドします。

| ワークフロー | 内容 | 置き場所 |
|---|---|---|
| iOS Build（`.github/workflows/ios.yml`） | テスト・スクリーンショット・未署名 ipa | Releases の `build-番号`、スクショは `ci-screenshots` ブランチ |
| Windows Build（`.github/workflows/windows.yml`） | 単体で動く exe（.NET 8 同梱） | Releases の `pc-build-番号` |

## 構成

```
Shared/            データ・中継の受け取り・保存・ウィジェットの見た目（アプリとウィジェットで共通）
Batteries/         iPhone アプリ本体（SwiftUI）
BatteriesWidget/   ウィジェット（WidgetKit）
BatteriesTests/    ユニットテスト
pc/BatteriesPC/    Windows の常駐アプリ（C# / WinForms、AirPods の電波の読み取り）
tools/icon.py      アプリアイコンの生成
project.yml        XcodeGen の設定
```
