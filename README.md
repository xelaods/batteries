# バッテリー（batteries）

iPhone の周りの機器の電池残量を表示するアプリとウィジェットです（SwiftUI、iOS 17 以降）。
標準のバッテリーウィジェットと違い、**接続が切れても最後に読み取った値と時刻を表示し続けます**。

## 読み取れるもの

| 機器 | 方法 | 更新されるタイミング |
|---|---|---|
| iPhone 本体 | iOS の電池情報 | アプリを開いている間 |
| AirPods・Beats | AirPods が周りに発信している電波（近接ペアリング信号）を読む | アプリを開いている間（ケースを開けると見つかりやすい） |
| BLE のキーボード・マウスなど | 標準の電池サービス（0x180F）を読む | アプリを開いている間 |
| ノートPC・マウス（2.4GHz） | Windows の常駐アプリから送る | **次の段階で追加予定** |

- AirPods は左・右・ケースを別々に記録し、来なかった値（ケースを閉じている間など）は前の値をそのまま残します
- 周りの人の AirPods を拾わないよう、一定より強い電波で、同じ機種の中でいちばん強いものだけを記録します（設定で基準を変えられます）
- iOS の制限で、アプリを閉じている間は AirPods の電波を受け取れません。ウィジェットをタップするとアプリが開いて読み取ります

### まず確かめること（診断）

AirPods の信号を iOS がアプリに渡してくれるかは、実機で試すまで分かりません。
アプリ左上の波形アイコン（診断）で、**AirPods のケースを開けて iPhone のすぐ横に置いた状態**で「30秒間 調べる」を押してください。

- 「AirPods の信号」が増えていく → 読み取れます
- 「Apple の電波」は増えるのに「AirPods の信号」が 0 のまま → iOS がこの信号を渡していないので、別の方法を考えます

左右が逆に表示される場合は、設定の「左右を入れ替える」をオンにしてください。

## ウィジェット

| 大きさ | 内容 |
|---|---|
| 小 | 丸いメーターを最大4つ（1台だけなら大きく） |
| 中 | 丸いメーターを4つ横に並べ、古い値は「◯時間前」と表示 |
| 大 | 一覧（左右の内訳、最後に受け取った時刻つき） |
| ロック画面 | 長方形（3台）・円（1台）・1行 |

署名に App Group が入っていればそれで共有します。入っていない場合（普段の署名ツール）は、MoneyPlan と同じように**カレンダーの 2001年1月3日にメモを1件だけ**保存してウィジェットに渡します。初回は「設定 › ウィジェット › カレンダーへのアクセスを許可」をタップしてください。

### ショートカット

「バッテリーを更新」アクションがあります。オートメーション（例：AirPods に接続したとき）に入れると、アプリが開いて自動で読み取ります。

## IPA の作り方（Mac 不要）

`main` に push すると、GitHub Actions（`.github/workflows/ios.yml`）が自動でビルドします。手動で動かすときは **Actions** タブ →「iOS Build」→「Run workflow」。

1. **Releases** の最新（`build-番号`）から `Batteries-unsigned-番号.ipa` をダウンロード（Actions の Artifacts にも置いています）
2. 普段使っている署名ツールで署名してインストール

ビルドの途中で、AirPods の信号の読み取りと「最後の値を残す」処理のテストも行います。見本データでの各画面のスクリーンショットは `ci-screenshots` ブランチに置かれます。

## 構成

```
Shared/            データ・AirPods 信号の読み取り・保存・ウィジェットの見た目（アプリとウィジェットで共通）
Batteries/         アプリ本体（SwiftUI）と Bluetooth の読み取り
BatteriesWidget/   ウィジェット（WidgetKit）
BatteriesTests/    ユニットテスト
tools/icon.py      アプリアイコンの生成
project.yml        XcodeGen の設定
```

データは端末の中にだけ保存し、外部には送りません。
